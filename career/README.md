# Career / Job-Search Memory — Manish Kumar Yadav

This folder is the saved memory for job searching. Sessions are temporary, so new sessions read from these files.

| File | Purpose |
|---|---|
| `PROFILE.md` | Resume facts, skills, strengths, target roles (source of truth) |
| `JOB_ROLES.md` | Voice-AI job roles that match the profile, plus real openings found |
| `APPLICATIONS.md` | Tracker: every job shared or applied to, with status |

## How to use (for Claude / any agent)
1. Read `PROFILE.md` before matching or tailoring anything.
2. When the user shares a job (link or JD): score the fit against `PROFILE.md`, list the skill gaps,
   suggest resume bullets to tailor, and add a row to `APPLICATIONS.md`.
3. When the user shares new experience, projects or a new resume: update `PROFILE.md` and note the date.
4. When searching for jobs: add new openings to `JOB_ROLES.md` → "Live openings", with the date found.

Contact details (phone, email) are left out on purpose. They are on the PDF resume.
